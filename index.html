How this archive works
AREDDL fetches levels currently rated Easy Demon from the Geometry Dash search database, then displays each level's reported game version. Use the version filter to narrow the archive from 1.0 to 2.2. The API is paginated, so use the loading buttons to progressively retrieve more entries; this avoids pretending a partial first page is the entire list.

*Rank note: Rank is the order returned by the search service, not an AREDL difficulty placement or community vote. Ratings and level availability can change. Some old levels may have been updated after their original release.
